# ميثاق وقواعد تعريب رواية ORV (Omniscient Reader's Viewpoint)

## 1. الأمانة الأدبية الصارمة (Zero Hallucination Policy)
- **منع التأليف أو الاختلاق:** أنت مترجم ولست مؤلفاً. لا تقم أبداً بإضافة حوارات، أفعال، مشاعر، أو وصف غير موجود في النص الإنجليزي الأصلي.
- **منع الحذف أو التلخيص:** ترجمة كل فقرة وجملة بالكامل دون تفويت أي معنى.
- **الحفاظ على البنية:** مطابقة هيكل الفقرات والأسطر الأصلية تماماً.

## 2. البلاغة والأناقة السردية المتوازنة
- **فصاحة أدبية أنيقة دون تقعر نيش (Ultra-niche):**
  - المفردات الأدبية البليغة الطبيعية مرحب بها (مثل: *خالجني، راودني، أكابد، حرياً، انتابني، أحجمتُ*).
  - منع الألفاظ الشعرية المعجمية النيش أو المفرطة في القدم والغرابة (مثل: *شجن، وصب، كرى، تباريح، إلخ*).
- **نبذ "كان / وكانت" كترجمة لفعل الكينونة (was/were):** استخدام أفعال ماضية صريحة وطبيعية دون ركاكة.
- **التخلص من ركاكة "تم + المصدر":** استخدام أفعال مباشرة وحية.
- **صوت ونبرة الراوي (كيم دوكجا - Kim Dokja):**
  - فصحى معاصرة رشيقة وذكية، واقعية، تعكس شخصية شاب قارئ وموظف ذكي.
- **رسائل النظام وإشعارات الكوكبات:** لغة إجرائية مقتضبة وحاسمة تحاكي شاشات واجهات الألعاب والحواسيب الفضائية:
  - `[انطلق السيناريو الرئيسي الأول!]`
  - `[الكوكبة 'قاضية النار شبيهة الشياطين' تنظر إليك.]`
- **حوارات الدوكايبى (Dokkaebi):** نبرة مسرحية واستعراضية ومستفزة.

## 3. معايير علامات التنصيص والترقيم
- `" ... "` : للحوارات المنطوقة بصوت مسموع بين الشخصيات.
- `' ... '` : للتفكير الداخلي، الألقاب، وأسماء الأعمال المختصرة.
- `「 ... 」` : لنصوص الرواية المقتبسة ورسائل الكاتب المكتوبة داخل المنصة.
- `[ ... ]` : لرسائل النظام، أسماء الفصول المكتملة، والشاشات العائمة.

## 4. ذاكرة المصطلحات والأسماء (Memory & Consistency)
- الالتزام التام بقاموس `novel_memory.json`.
- أي اسم شخصية، كوكبة، مهارة، أو مكان مسجل مسبقاً يمنع تغييره.
- تسجيل أي مصطلح أو اسم جديد فوراً في القاموس.

## 5. صيغة الملفات والصور (Markdown & Images)
- `raw_en/`: فصول الرواية بصيغة Markdown (`.md`) بالإنجليزية وتتضمن روابط الصور `![alt](url)`.
- `translated_ar/`: يتم حفظ جميع الفصول المترجمة بصيغة **`.md`** (مثل: `ch_1_ar.md`).
- **الصور المضمنة:** الحفاظ التام على روابط الصور `![alt](url)` كما هي وإدراجها في مواضعها المحددة بدقة داخل ملفات الترجمة `.md`.
- `memory/novel_memory.json`: قاعدة بيانات المصطلحات وسجل التقدم المحدث بعد كل فصل.
