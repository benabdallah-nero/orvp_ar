# مجلد الذاكرة والتعليمات - Memory & Instructions

هذا المجلد يحتوي على جميع ملفات التوجيهات والقواعد والذاكرة المستخدمة في مشروع تعريب رواية ORV.

## الملفات الموجودة

### 1. `TRANSLATE.md` (8 KB)
**الغرض:** تعليمات الترجمة الكاملة من الإنجليزية إلى العربية
**متى تستخدمه:** عند ترجمة فصل جديد من `raw_en/` إلى `translated_ar/`
**الأمر:** "اتبع تعليمات `memory/TRANSLATE.md` وترجم الفصل X"

### 2. `REVISE.md` (11 KB)
**الغرض:** تعليمات المراجعة والتحسين لإزالة الركاكة من الترجمات
**متى تستخدمه:** بعد الترجمة، لتحسين جودة النص العربي
**الأمر:** "اتبع تعليمات `memory/REVISE.md` وراجع `translated_ar/1_ar.txt`"

### 3. `translation_rules.md` (3.4 KB)
**الغرض:** القواعد الأساسية لأسلوب الترجمة (النسخة الأصلية)
**الاستخدام:** مرجع عام للقواعد الأساسية

### 4. `novel_memory.json` (3.3 KB)
**الغرض:** قاعدة بيانات المصطلحات والأسماء
**المحتوى:**
- أسماء الشخصيات (كيم دوكجا، يو سانغاه، إلخ)
- المصطلحات التقنية (سيناريو، كوكبة، دوكايبي)
- العناوين والألقاب
- الأماكن والفصائل
**الاستخدام:** يجب قراءته وتحديثه مع كل فصل جديد للحفاظ على الاتساق

## سير العمل الموصى به

### للترجمة:
```
1. اقرأ memory/TRANSLATE.md
2. اقرأ memory/novel_memory.json
3. ترجم الفصل من raw_en/
4. احفظ في translated_ar/
5. حدّث novel_memory.json بالمصطلحات الجديدة
```

### للمراجعة:
```
1. اقرأ memory/REVISE.md
2. اقرأ الترجمة من translated_ar/
3. راجع وحسّن الصياغة
4. احفظ النسخة المحسّنة
5. تحقق من المصطلحات في novel_memory.json
```

## ملاحظات مهمة

- **كل الملفات بترميز UTF-8** لدعم العربية بشكل صحيح
- **TRANSLATE.md و REVISE.md مكتوبان بالعربية** لسهولة الفهم
- **لا تعدّل novel_memory.json يدوياً** إلا للتصحيحات المهمة
- **أضف المصطلحات الجديدة فوراً** للحفاظ على الاتساق

## الفرق بين TRANSLATE و REVISE

| الجانب | TRANSLATE | REVISE |
|--------|-----------|--------|
| الهدف | ترجمة جديدة | تحسين موجود |
| المدخل | نص إنجليزي | نص عربي مترجم |
| التركيز | الأمانة والاكتمال | التدفق والطبيعية |
| التغيير | من لغة للغة | تحسين الصياغة |
